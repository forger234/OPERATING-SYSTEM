⚙️ Operating System Algorithms in C

This repository contains C programs implementing classic Operating System concepts, including scheduling algorithms, inter-process communication, synchronization problems, and basic file systems. Ideal for academic practice and systems programming enthusiasts.

📁 Contents
| File Name                   | Description                                  |
| --------------------------- | -------------------------------------------- |
| `BankersAlgorithm.c`        | Banker's Algorithm for deadlock avoidance    |
| `BinarySearchTree.c`        | Binary Search Tree implementation            |
| `DinningPhilosopher.c`      | Dining Philosopher problem (synchronization) |
| `Directory.c`               | Simulated file directory structure           |
| `FCFS.c`                    | First-Come-First-Serve scheduling            |
| `FIFO.c`                    | FIFO page replacement                        |
| `IPCreader.c`               | Inter-process communication (reader)         |
| `IPCwriter.c`               | Inter-process communication (writer)         |
| `PriorityScheduling.c`      | Priority-based scheduling                    |
| `ProcessCreation.c`         | Process creation using function calls        |
| `ProducerConsumerProblem.c` | Producer-Consumer problem using semaphores   |
| `Roundrobin.c`              | Round Robin CPU scheduling                   |
| `SJF.c`                     | Shortest Job First (Non-preemptive)          |
| `SJFAT.c`                   | SJF with Arrival Time (Preemptive)           |
| `StringStack.c`             | Stack implementation for strings             |

🔍 Topics Covered

    🧵 Process Scheduling: FCFS, SJF, Priority, Round Robin

    🔐 Synchronization: Producer-Consumer, Dining Philosophers

    📡 Inter-process Communication: IPC Reader & Writer

    🗃️ File Management: Directory simulation

    📈 Memory & Page Replacement: FIFO

    🌲 Data Structures: BST, Stack

✅ How to Compile & Run

# Compile
gcc FCFS.c -o fcfs

# Run
./fcfs

Replace FCFS.c with any other file to test its functionality.
📌 Requirements

    GCC Compiler or any standard C compiler

    Basic knowledge of operating systems and C programming
